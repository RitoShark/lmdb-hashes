# Security

## Supported code

Security fixes target the current builder and version 2 format. Legacy LMDB
release files remain available for migration but are no longer rebuilt here.

## Reporting

Report vulnerabilities privately to the maintainers. Use the repository's
Security tab to report a vulnerability if private reporting is available;
otherwise use a maintainer's private contact method listed on their GitHub profile.
Do not include exploit details or private information in a public issue.

Useful reports include a reproduction, affected version, and expected impact.
Examples include unintended file writes, compromised download handling, or a
release workflow exposing credentials or publishing untrusted artifacts.

Ordinary format errors, unresolved names, and incorrect source data can be
reported through normal issues. Never attach credentials or copyrighted game assets.
